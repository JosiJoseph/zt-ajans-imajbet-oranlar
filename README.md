# ZT Ajans – İmajBet Oranlar

NERA'dan bağımsız, mobil uyumlu veri görüntüleme pilotu.

**Durum:** 20 Kasım 2026 ekran görüntülerindeki oranlar örnek kayıt olarak gösteriliyor. Otomatik canlı veri toplama doğrulanmış değildir. Sayfa veriyi `data/latest.json` dosyasından okur; bu dosya değiştirilirse ekran güncellenir. Alan adları kaynak adayıdır ve güncel/resmî oldukları garanti edilmez.

Güncel oran bilgisi için yetkili ve izinli veri kaynağı doğrulanmadan verileri canlı diye işaretlemeyin.
